# Layer performance — sm_120 (NVIDIA RTX 5090)

Each table times one whole MLP or MoE block as a single CUDA-graph replay with
cold weights, on an RTX 5090 locked at 2407 MHz. ×fso is a comparator's µs over
fso's µs at the same M, so above 1 means fso is faster; decode is M 1–128,
prefill M > 128. Family A's fso reference is the MXFP8 block, the path
`fso.dense` serves here. Method: [`../README.md`](../README.md); columns:
[`README.md`](README.md); runs: [Environments of record](../README.md#environments-of-record).

## Comparators

Versions are those that `bench/env/5090.lock.json` pins for its `main`,
`sglang` and `fi` environments; the environments block shows what each run
found.
