## Family C — Qwen3.5-35B-A3B MoE block (E=256, top-8, moe_inter 512, shared expert 512)

fso routed: same contiguous BSFP8 layer as Family B. fso routed + shared:
the routed layer plus the shared expert (`gate_up` 1024×2048 → compiled
silu·mul → quantize → `down` 2048×512, BSFP8) and the residual add, one graph.
Block TFLOPS, GB/s, cos and `model ms` (× 40 layers) are for the routed +
shared column; `shared expert µs` is the difference between the two fso
