# Layer performance — sm_100 / sm_103 (NVIDIA B300)

Each table times one whole MLP or MoE block as a single CUDA-graph replay with
cold weights, at the B300's natural clock (the pod cannot lock it). ×fso is a
comparator's µs over fso's µs at the same M, so above 1 means fso is faster;
decode is M 1–128, prefill M > 128. Family A's fso reference is the MXFP8 block,
the path `fso.dense` serves here. Method: [`../README.md`](../README.md);
columns: [`README.md`](README.md); runs: [Environments of record](../README.md#environments-of-record).

## Comparators
