# Attention performance — sm_90 (NVIDIA H200)

**n/a — fish-scales-ops has no native sm_90 attention kernel.**

The attention backends in `python/fish_scales_ops/attention/backends/` are all
sm_120 MXFP8 kernels (`sm120_mxfp8`, `sm120_mxfp8_decode`,
`sm120_mxfp8_paged_prefill`). On sm_90 `flash_attn_fwd` dispatches to the torch
SDPA fallback, which is not fso code, so no numbers are published here.

This file exists so the sm_90 attention target is stated explicitly rather than
omitted. If a native sm_90 attention path is added, this file follows the
structure of [`sm120.md`](sm120.md) (same head configurations, same table kinds,
no comparison columns).
