# Attention performance — sm_100 / sm_103 (NVIDIA B300)

**n/a — fish-scales-ops has no native sm_100 attention kernel.**

All attention backends are sm_120 MXFP8 kernels; on sm_100 / sm_103
`flash_attn_fwd` dispatches to the torch SDPA fallback, which is not fso code,
so no numbers are published here.

This file exists so the sm_100 attention target is stated explicitly rather
than omitted. If a native sm_100 attention path is added, this file follows the
structure of [`sm120.md`](sm120.md).
