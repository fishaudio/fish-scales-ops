# Attention performance — sm_120 (NVIDIA RTX 5090)

These tables cover fso's MXFP8 attention kernels on sm_120: contiguous prefill, paged decode and paged prefill /
extend. Rows time the attention kernel on pre-quantized MXFP8 inputs, so quantization is not part of the time; `cos`
is the cosine similarity of the output against a BF16 SDPA reference on the same inputs. The RTX 5090 is clock-locked
with `nvidia-smi -lgc 2407`, which reads 2400 MHz; the method is in [`../README.md`](../README.md). No attention run
has been accepted yet, so the result tables below are still empty.

## Head configurations

The attention tables use the head geometry of the GEMM shape families defined in [`../README.md`](../README.md):

| family | H_q | H_kv | D | layers with this attention |
|---|---|---|---|---|
| A — Qwen3-4B | 32 | 8 | 128 | all 36 |
| B — Qwen3-30B-A3B | 32 | 4 | 128 | all 48 (heads from public config — verify) |
| C — Qwen3.5-35B-A3B | 16 | 2 | 256 | the 10 full-attention layers only; the 30 Gated DeltaNet layers are not attention GEMM work and are out of scope |
